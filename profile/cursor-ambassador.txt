# Cursor Ambassador — Malik

## Rôle

Premier ambassadeur Cursor en France (depuis ~2025).

Un ambassadeur Cursor est une personne mandatée par Cursor pour :
- Créer du contenu autour de Cursor (posts, tutoriels, démos)
- Enseigner l'utilisation de Cursor à de nouveaux utilisateurs
- Organiser des événements pour faire grandir l'adoption de Cursor dans son pays
- Représenter Cursor dans sa communauté locale

Malik est le **premier ambassadeur français de Cursor**.

---

## Événements organisés

### Événement 1 — avec Amo (ex-Zenly / Snapchat Map)
- **Co-organisateur :** Amo (startup connue pour avoir créé Zenly, rachetée par Snapchat, et la Snapchat Map)
- **Contenu :** Talk de 30 min sur les Cursor Rules
  - Comment utiliser les rules pour donner plus de contexte à l'IA et shipper du meilleur code
  - Démo live : utiliser des regex dans les rules pour cibler des types de fichiers spécifiques dans une architecture et y appliquer automatiquement la documentation et les conventions de code
- **Audience :** ~100 personnes
- **Résultat :** Fort engagement sur les réseaux, beau bruit médiatique

### Événement 2 — avec Hexa (incubateur de startups, Swan, etc.)
- **Co-organisateur :** Hexa, incubateur parisien (startups notables : Swan)
- **Invité spécial :** Nick Miller, ingénieur Cursor (venu en personne depuis San Francisco)
- **Audience :** >100 personnes
- **Résultat :** Événement remarqué, présence physique d'un Cursor engineer rare en Europe

### Événement 3 — avec ORUS
- **Co-organisateur :** ORUS
- **Audience :** ~100 personnes
- **Résultat :** Succès similaire aux précédents

### Événement 4 — avec Alan (à venir)
- **Date :** 28 mai 2026
- **Lieu :** Bureaux d'Alan
- **Audience prévue :** ~100 personnes
- **Contexte :** Organiser un événement Cursor dans les bureaux de l'entreprise où il postule en stage — signal fort de légitimité et de connexion avec l'équipe
